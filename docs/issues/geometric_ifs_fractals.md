# Геометрические IFS-фракталы

## Статус

Запланировано.

Поддержка deep zoom в первую версию не входит.

## Цель

Добавить отдельное семейство детерминированных самоподобных фракталов:

- треугольник Серпинского;
- ковёр Серпинского;
- Vicsek fractal;
- рекурсивные квадраты и прямоугольники на основе настраиваемого набора
  аффинных преобразований.

В отличие от escape-time формул эти фракталы строятся повторным применением
геометрических правил. В отличие от Fractal Flame выбор преобразований
детерминирован, а результат не требует стохастического накопления плотности.

## Renderer

Для MVP использовать аналитический fragment shader:

1. Преобразовать координату пикселя в локальные координаты базовой фигуры.
2. На каждом уровне определить дочернюю ячейку.
3. Отбросить пиксель, если эта ячейка исключена правилом фрактала.
4. Повторять до выбранной глубины либо пока размер ячейки не станет меньше
   пикселя.

Такой подход не создаёт на CPU тысячи треугольников или прямоугольников и
сохраняет почти постоянную стоимость кадра при увеличении глубины рекурсии.

Shader должен иметь фиксированный безопасный верхний предел цикла, а реальная
глубина передаваться через uniform.

## Режим глубины

Добавить два режима:

- `Auto` — renderer выбирает глубину по масштабу и физическому размеру пикселя;
- `Manual` — пользователь задаёт число уровней явно.

В режиме `Auto` рекурсия должна прекращаться, когда следующий уровень уже не
создаёт различимой геометрии. При увеличении камера открывает новые уровни без
резкого скачка изображения.

Это не arbitrary-precision deep zoom: максимальная глубина остаётся ограничена
точностью WebGL и безопасным числом shader-итераций.

## Фракталы MVP

### Треугольник Серпинского

- Базовая фигура — равносторонний треугольник.
- На каждом уровне сохраняются три угловых треугольника.
- Камера должна сохранять пропорции фигуры при любом aspect ratio.
- Опциональная окраска по уровню рекурсии не должна менять геометрию.

### Ковёр Серпинского

- Базовая фигура — квадрат.
- Деление каждого уровня на сетку `3×3`.
- Центральная ячейка исключается.
- Алгоритм определения ячейки должен быть устойчив на границах и не создавать
  мерцающие швы при движении камеры.

### Vicsek fractal

- Базовая фигура — квадрат.
- Деление на сетку `3×3`.
- Первый preset сохраняет центральную и четыре угловые ячейки.
- Предусмотреть второй preset с центральной и четырьмя осевыми ячейками.

## Расширяемое описание правил

После реализации MVP добавить declarative-конфигурацию deterministic IFS:

- идентификатор и название;
- базовая область и начальная камера;
- список affine transforms;
- коэффициент сокращения;
- маска сохраняемых ячеек для grid-based правил;
- рекомендуемая максимальная глубина;
- способ окрашивания.

Grid mask подходит для ковра Серпинского, Vicsek и рекурсивных прямоугольников.
Произвольные affine transforms нужны для треугольника и будущих
несеточных вариантов.

Не следует генерировать уникальный GLSL-код из пользовательского ввода.
Конфигурация должна преобразовываться в проверенные uniforms либо в один из
зарегистрированных shader backend'ов.

## UI

- Выбор geometric IFS-фрактала в общем списке формул.
- `Auto`/`Manual` для глубины рекурсии.
- Числовое поле глубины в ручном режиме.
- Выбор окраски: однотонная, по уровню, градиент.
- Цвет фигуры и фона либо совместимость с существующими палитрами.
- Для grid-based правил — выбор зарегистрированного preset без произвольного
  редактирования маски в MVP.
- Нерелевантные параметры escape-time renderer'а должны быть скрыты.

## Архитектурные изменения

- Добавить тип renderer'а `geometric-ifs` в общий renderer registry.
- Переиспользовать существующую 2D-камеру, pan, wheel zoom и touch-жесты.
- Отделить `recursionDepth` от `maxIterations`: это разные пользовательские
  понятия.
- Разрешить renderer'у определять собственный набор контролов.
- Сохранить общие lifecycle-операции `resize`, `render` и `dispose`.
- Не запускать worker: аналитический MVP полностью выполняется на GPU и не
  содержит дорогой подготовки на CPU.

## Порядок внедрения

1. Добавить `geometric-ifs` в renderer registry.
2. Реализовать общий fullscreen renderer с автоматической глубиной.
3. Добавить ковёр Серпинского как простейшее grid-based правило.
4. Добавить два варианта Vicsek fractal.
5. Добавить треугольник Серпинского и поддержку треугольной базовой области.
6. Выделить конфигурацию grid masks и affine transforms.
7. Добавить окрашивание по уровню и visual-regression presets.

## Критерии готовности

- [ ] Треугольник и ковёр Серпинского корректно отображаются на всех
      поддерживаемых aspect ratio.
- [ ] Реализованы оба preset Vicsek fractal.
- [ ] Режим `Auto` добавляет уровни по мере увеличения без заметных скачков.
- [ ] Ручная глубина воспроизводимо отображает выбранное число уровней.
- [ ] На границах ячеек нет мерцающих швов при pan и zoom.
- [ ] Количество CPU-объектов не растёт экспоненциально с глубиной.
- [ ] Управление камерой остаётся интерактивным на максимальной глубине.
- [ ] UI скрывает настройки escape-time и показывает настройки рекурсии.
- [ ] Для правил разбиения есть unit-тесты принадлежности точек.
- [ ] Для каждого MVP-фрактала есть browser visual-regression test.
- [ ] Существующие renderer backend'ы не имеют регрессий.

## Вне текущей задачи

- Deep zoom и arbitrary-precision координаты.
- Стохастические Fractal Flame и chaos game.
- L-системы, кривые Коха и Dragon curve.
- Визуальный редактор произвольных IFS-преобразований.
- Экспорт в SVG или генерация геометрической сетки.
