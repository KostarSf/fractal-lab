# Deep zoom для Newton и Nova

## Статус

Реализовано.

Оба `root-basin` фрактала автоматически переходят на perturbation renderer при
увеличении `10 000×` и используют общий предел `1e35×`. Reference-орбита
рассчитывается с произвольной точностью в существующем worker, а обычный basin
shader остаётся быстрым renderer'ом до порога.

## Рекуррентность

Для кубического correction

\[
C(z)=\frac{z^3-1}{3z^2}
=\frac z3-\frac{1}{3z^2}
\]

разность между фактической и опорной орбитами вычисляется без вычитания двух
близких значений `C`:

\[
\Delta C
=

\frac13\left(
\delta+
\frac{\delta(2Z+\delta)}
{Z^2(Z+\delta)^2}
\right)
\]

Newton использует

\[
\delta_{n+1}=\delta_n-\Delta C_n
\]

с начальным условием `δ₀ = δz` пикселя. Для Nova:

\[
\delta_{n+1}
=

\delta_n-r\Delta C_n+\delta c,\qquad \delta_0=0
\]

Изменение `relaxation` пересчитывает reference-орбиту Nova. `tolerance` и
`escapeRadius` остаются GPU-uniform'ами и не запускают worker повторно.

## Реализация

- `newton-cubic-perturbation` и `nova-cubic-perturbation` зарегистрированы как
  deep-zoom backend'ы формул.
- Arbitrary-precision worker поддерживает комплексное деление и безопасно
  пропускает сингулярную опорную точку `z = 0` при выборе reference.
- `deep-zoom-basin-shader.ts` сохраняет классификацию трёх корней, отдельный
  цвет выхода Nova и существующее сглаживание basin renderer'а.
- Newton хранит perturbation delta как нормализованные мантиссу и экспоненту.
  Это не даёт сжимающему участку орбиты обнулить отклонение пикселя перед
  последующим расширением. Рациональный perturbation factor вычисляется через
  последовательно нормализованное комплексное деление без underflow около
  полюса.
- При исчерпании орбиты или приближении к критической точке выполняется
  rebasing на начало reference-орбиты. Newton использует полную автономную
  reference-орбиту без разрушающего точность rebasing.
- Unit-тесты сопоставляют обе perturbation-рекуррентности с прямым шагом
  формулы и проверяют reference-орбиты.
- Оба shader'а скомпилированы и отрисованы в реальном WebGL2-контексте Chrome.
  Newton дополнительно проверен на увеличениях от `1e28×` до `1e35×` при
  центре:

  ```text
  1.261734435999730917660226160714876 + 1.532704545089778066177656844939145i
  ```

## Ограничения

Для Nova отклонение пикселя хранится в `highp float`; Newton использует
нормализованную мантиссу с отдельной экспонентой. Общий предел камеры остаётся
`1e35×`. Окрестность полюса `z = 0`, в которой производная вырождается,
остаётся неразрешённой так же, как в обычном root-basin shader.
