# Fractal Lab

Интерактивная лаборатория фракталов в браузере. Приложение визуализирует
escape-time-фракталы, бассейны притяжения, странные аттракторы и геометрические
IFS с помощью WebGL2, а тяжёлые вычисления выносит в Web Workers.

## Возможности

- 12 встроенных фракталов с поиском, фильтрами и живыми превью;
- GPU-рендеринг с временным снижением разрешения во время навигации;
- автоматический deep zoom для поддерживаемых формул при увеличении от `10 000×`;
- высокоточная камера и расчёт опорной орбиты через `decimal.js`;
- отдельный worker для траектории аттрактора Клиффорда;
- настраиваемые параметры формул, число итераций, палитры, сглаживание и
  плотность цвета;
- автоматическая или ручная глубина рекурсии для геометрических IFS;
- управление мышью, клавиатурой и touch-жестами;
- адаптивный интерфейс для настольных и мобильных экранов.

### Доступные фракталы

| Категория           | Фракталы                                                                  |
| ------------------- | ------------------------------------------------------------------------- |
| Escape time         | Множество Мандельброта, множество Жюлиа, Burning Ship, Трикорн, Феникс    |
| Бассейны притяжения | Newton, Nova                                                              |
| Странные аттракторы | Clifford attractor                                                        |
| Геометрические IFS  | Треугольник Серпинского, ковёр Серпинского, Vicsek · углы, Vicsek · крест |

## Запуск

Понадобятся современный браузер с поддержкой WebGL2 и CLI
[Vite+](https://viteplus.dev/guide/) (`vp`). В CI проект собирается на Node.js 24.

```bash
vp install
vp dev
```

После запуска Vite+ выведет локальный адрес приложения в терминал.

### Остальные команды

```bash
# Форматирование, линтинг и проверка типов
vp check

# Тесты
vp test

# Production-сборка в dist/
vp run build

# Локальный просмотр production-сборки
vp preview
```

## Управление

| Действие                 | Мышь и клавиатура                 | Touch                 |
| ------------------------ | --------------------------------- | --------------------- |
| Перемещение              | перетаскивание или стрелки        | один палец            |
| Масштабирование          | колесо, `+` / `-`                 | жест двумя пальцами   |
| Быстрое приближение      | двойной клик                      | —                     |
| Каталог фракталов        | `Ctrl+K` / `⌘K`                   | кнопка выбора формулы |
| Возврат к исходному виду | кнопка сброса в панели параметров | та же кнопка          |

Набор настроек справа зависит от выбранного рендерера. Например, для
escape-time-фракталов доступны итерации и сглаживание, для Clifford attractor —
параметры траектории и экспозиция, а для IFS — глубина рекурсии и способ
окрашивания.

## Как устроен проект

```text
src/
├── attractors/       # расчёт траектории Clifford и worker-клиент
├── components/       # интерфейс, canvas и каталог фракталов
├── deep-zoom/        # опорные орбиты и perturbation backends
├── fractals/         # реестр формул, типы и генерация shader-кода
├── geometric-ifs/    # правила и пресеты геометрических IFS
├── math/             # высокоточная камера и преобразования координат
├── renderer/         # WebGL2-рендереры и GLSL shaders
└── stores/           # состояние камеры и параметров в Pinia
```

Обычные escape-time-фракталы и бассейны рассчитываются fragment shader’ами.
Clifford-траектория сначала строится в worker, затем отображается GPU как облако
точек. Геометрические IFS используют аналитическую рекурсию в shader. Для
глубокого увеличения worker вычисляет высокоточную опорную орбиту, а GPU
продолжает расчёт методом perturbation.

Deep zoom доступен для пяти escape-time-формул, Newton и Nova. Увеличение
ограничено значением `1e35×`: координаты камеры и опорная орбита сохраняют
произвольную точность, но отклонение пикселя в WebGL2 shader остаётся
`highp float`.

## Добавление фрактала

- Формулы escape time, бассейны и аттракторы регистрируются в
  [`src/fractals/formulas.ts`](src/fractals/formulas.ts).
- Геометрические IFS и их affine transforms находятся в
  [`src/geometric-ifs/presets.ts`](src/geometric-ifs/presets.ts).
- Новый способ рендеринга оформляется отдельным backend’ом в `src/renderer/`.
- Для deep zoom потребуются формулозависимые recurrence и регистрация backend’а
  в `src/deep-zoom/`.
- Изменения реестра, математики или shader-кода следует покрыть тестами рядом с
  соответствующим модулем.

Технические заметки и запланированные улучшения собраны в
[`docs/issues`](docs/issues/).
